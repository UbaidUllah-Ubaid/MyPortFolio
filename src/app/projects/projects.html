My Projects

Some of the projects I have built while learning modern web development.

01

Investment Calculator

I built this project to understand how Angular handles user input, calculations and dynamic data rendering. The user enters the initial investment, annual contribution, expected return and investment duration.

After submitting the form, the application calculates the expected investment value for every year and displays the results in a table.

How I Built It

The project was developed using Angular and TypeScript. I used Angular components to separate the UI and application logic, and used data binding to receive the user's input and display the calculated results dynamically.

Technologies

HTML CSS Bootstrap Angular TypeScript
Live Demo GitHub
02

UserHub

UserHub is a responsive Angular dashboard that I created to practice working with APIs and displaying real-world user data in a clean interface.

Users can view different profiles, open their details, see their posts and view comments related to each post. The application loads the data dynamically from an API.

How I Built It

I built UserHub using Angular services to communicate with the API. Components are used for users, posts and comments, while Angular routing is used to navigate between different views.

Technologies

HTML CSS Bootstrap TypeScript Angular REST API
Live Demo GitHub
03

Blog Website

I built this blog project to practice working with REST APIs and understand how frontend applications communicate with backend services.

Users can view available blogs, open a specific blog and interact with its content. The frontend receives blog and comment data from the backend API.

How I Built It

The project was created using HTML, CSS and JavaScript. I used the Fetch API to communicate with the backend and dynamically rendered blogs and comments on the page.

Technologies

HTML CSS JavaScript REST API Backend Server
Live Demo GitHub
